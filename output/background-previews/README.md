Three experimental backgrounds generated directly at 128 × 64 with PixelLab PixFlux. The built-in ImageGen trial returned 1774 × 887 and was rejected.

Native outputs: *-128x64-1bit.png. Original generator files: *-128x64-source.png. Preview files use nearest-neighbor integer scaling only and are not source assets.

Castle: source had 36 colors; converted to 1 bit using luminance threshold 128 without resizing or dithering. Forest and sci-fi: generated with forced black/white palette. All three native files verified as 128 × 64 and two colors. Pixel rows for the editor are in background-pixels.json (1 = white, 0 = black). No library changes made.
